# Smart-table
Модуль, создающий таблицу по HTML шаблону, заполняемую данными с удаленного сервера. 
Предоставляет возможности сортировки, фильтрации и поиска данных, навигации по таблице с использованием элементов пагинации.

Учебный проект курса Frontend-разработчик Яндекс Практикум
**Технологии:** HTML, CSS, JavaScript, Vite

## Цели проекта
Освоить на практике:
 - управление DOM-элементами ,
 - обработку событий,
 - обработку данных из формы, 
 - подготовка и выполнение GET-запроса c query параметрами,
 - наполнение HTML данными с сервера
## Возможности
- Наполнеие таблицы данными с удаленного сервера
- Управление набором данных:
    - Пагинация
    - Сортировка
    - Фильтрация
    - Глобальный поиск
